Pair each module from its own card. The browser discovers devices by the GaitIMU service UUID (which is in the primary advertisement), then identifies Torso / Left / Right from the module's ID characteristic — so picking the wrong dialog no longer matters.
Modules only transmit while streaming — press ▶ Start Streaming (or Start Recording, which starts streaming automatically) and watch the Packet/Sample counters rise on each card.
Battery level only appears if a module exposes a battery service (the ESP32-C3 firmware omits it).
Rows are interleaved per module; sort by unix_time_ms for chronological order. Keep sessions ≤ 15–20 min per trial.
