How to use (Android Chrome / PC Chrome-Edge · Web Bluetooth):
1. Flash each module with GaitSensorBoard.ino, giving each a unique DEVICE_NAME / MODULE_POSITION (Right Leg, Left Leg, Torso).
2. Connect the 3 modules (button on each card). Battery % appears automatically.
3. Press Sync time (IST) — the current epoch (UTC ms) is written to every module; modules timestamp their IMU samples against this reference (IST = UTC + 5:30).
4. Tick the modules to record, press Start recording, perform the gait trial, press Stop recording, then Download .csv.
5. Refresh data re-reads battery/info and live counters of connected modules.
Time is time-synced once via the host clock; the CSV carries timestamp_epoch_ms (UTC) plus an IST wall-clock column. Accel in g (±4 g), gyro in deg/s (±2000 dps). Packet loss is reported via the stream sequence counter.
