Gait IMU Recorder

3 × ESP32-C3 + MPU-6050 · 200 Hz · BLE / Web Bluetooth · time-synced CSV

How to use

  1. Power the three modules (battery or USB) and attach them: Right Leg, Left Leg, Torso.
  2. Click Pair Modules (BLE) — select GaitIMU-RightLeg, GaitIMU-LeftLeg and GaitIMU-Torso in the browser dialog (3 dialogs). Clocks are synced to Unix epoch automatically with multi-sample latency compensation.
  3. Start Streaming — each card should show ≈ 200 Hz and a live acceleration trace. Battery level appears on each card if the module provides it.
  4. Start Recording → perform the walking trial → Stop Recording. If a module drops out, it auto-reconnects (3 attempts) and rejoins the stream.
  5. Download CSV — one row per sample, with the module identifier in the first column.
This browser does not support Web Bluetooth. Use Chrome or Edge on Android, Windows, macOS or Linux (not iOS/Safari). On Android, enable Location Services (required for BLE scanning).
Tip: if the buttons stay disabled when opened as a local file, serve the page instead: python -m http.server → http://localhost:8000. Keep the tab open for the whole session — Web Bluetooth loses pairings on page reload.
